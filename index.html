为什么做这东西？

社交平台上通过拼音首字母缩写指代特定词句的情况越来越多，为了让更多人能勉强理解这一门另类沟通方式、做了这一个划词转义工具。

什么是用户脚本？

用户脚本是一段代码，它们能够优化您的网页浏览体验。安装之后，有些脚本能为网站添加新的功能，有些能使网站的界面更加易用，有些则能隐藏网站上烦人的部分内容。用户脚本都是由用户编写并向全世界发表的，您可以免费安装，轻松体验。

用户脚本管理器安装过程可参考 https://greasyfork.org/ 首页的，安装一个用户脚本管理器 章节

如何安装网页划词释义用户脚本？

安装好用户脚本管理器之后，访问 nbnhhsh.user.js 完成脚本安装

脚本版本目前会在 微博、贴吧、哔哩哔哩 页面下运行，划词时会提交所选文字以用于转义。划词浮窗支持批量列出缩写、点击复制，并用 ↑↓ 切换、Enter 确认。

整段解析

在首页切换到 整段解析，粘贴一整段文字后会自动给所有缩写加下划线，点击任意缩写可就地查看候选解释，并可一键复制带解释的完整译文。

我的词库

查询过的缩写会自动进入 查询历史（保存在本地，刷新不丢失）；可以收藏缩写、添加自定义解释（展示时优先于接口结果），支持删除单条、一键清空，也可以通过 JSON 文件导入导出，在网页版与用户脚本之间同步。

深色模式

默认跟随系统外观，点击右上角 ◐ 按钮可在 跟随系统 / 浅色 / 深色 之间切换，选择会被记住。

贡献词条

在每一个词条右上角都有 + 图标的按钮，点击可以提交对应文字，审核后会整理录入。
